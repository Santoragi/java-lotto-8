# java-lotto-precourse

## 로또 규칙
- 로또 번호의 숫자 범위는 1~45이다.
- 로또 한장의 금액은 1000원이다.
- 로또 당첨 기준과 금액은 다음과 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원

## 구현 기능 목록

1. 구입 금액 입력
   1. 구입 금액에 해당하는 로또 수량을 계산한다.
   2. 최소 구입 금액은 1000원이다.
   3. 최대 구입 금액은 10만원이다.
   4. 입력 금액이 1000원으로 나누어지지 않은 경우 예외 처리한다.
   
2. 로또 발행
   1. 한 장의 로또는 중복되지 않은 숫자 6개를 랜덤으로 뽑는다.
   2. 로또 수량만큼 로또를 발행한다.
   3. 발행된 로또의 총 수량을 출력한다.
   4. 각 로또의 번호를 오름차순으로 정렬하여 출력한다.

3. 당첨 번호 입력
   1. 당첨 번호는 중복되지 않은 숫자 6개를 입력받는다.
   2. 번호는 쉼표(,)를 기준으로 구분한다.
   3. 입력된 번호의 개수가 6개가 아니면 예외 처리한다.
   4. 중복되는 숫자가 입력되면 예외 처리한다.
   5. 번호의 범위를 벗어나면 예외 처리한다.

4. 보너스 번호 입력
   1. 보너스 번호는 숫자 1개를 입력받는다.
   2. 보너스 번호가 당첨 번호와 중복되면 예외 처리한다.
   3. 번호의 범위를 벗어나면 예외 처리한다.

5. 당첨 확인
   1. 발행된 각 로또의 번호와 당첨 번호, 보너스 번호를 비교하여 당첨 기준에 일치하는지 확인한다.
   2. 당첨 내역을 출력한다.
   
6. 수익률 계산
   1. 당첨 금액과 구입 금액을 통해 수익률을 계산한다.
   2. 수익률은 소수점 둘째 자리에서 반올림한다.
